# Frontend — S.A.M.V.A. Platform

Nuxt 4 app with Nuxt UI v4, Tailwind CSS 4, and TypeScript.

## Commands

```bash
npm install          # Install dependencies
npm run dev          # Dev server at http://localhost:3000
npm run build        # Production build
npm run generate     # Static generation
npm run preview      # Preview the build
npm run typecheck    # TypeScript check
npm run lint         # ESLint (lint only)
npm run lint:fix     # ESLint with auto-fix
npm run format       # Format all files with Prettier
npm run format:check # Check formatting without writing
```

The dev server needs the backend running at `http://localhost:8000`.

## Structure

```
app/                 # Vue app code
├── pages/           # Routes (/, /login, /dashboard, /dashboard/profile)
├── layouts/         # Layouts (default, login, dashboard)
├── components/      # Vue components (cms/, dashboard/, icons/)
├── composables/     # Domain composables (useAuth, useAccount)
├── middleware/      # Route middleware (auth, guest)
├── plugins/         # $api plugin (JWT header) + auth init on boot
└── utils/api/       # HTTP layer: fetcher, tokens, domain API modules
shared/              # Shared types and utils (alias #shared/)
server/              # Nitro server routes (empty for now)
```

## How things work

- **HTTP**: never call `fetch` directly. All requests go through the shared `fetcher` (`app/utils/api/fetcher.ts`). It adds the JWT `Authorization` header and refreshes the token on 401.
- **Domain APIs**: endpoints live in `app/utils/api/<domain>/` (`authApi`, `accountsApi`). Import them with the `#api` alias.
- **Auth**: JWT login with email + password. Tokens are stored in `localStorage`. The `auth` and `guest` middleware protect the routes.
- **State**: domain composables with Nuxt `useState`. No Pinia.
- **Formatting**: Prettier formats the code; ESLint only lints. Do not add style rules to `eslint.config.mjs`.

## Architecture

The frontend is migrating from a layered structure to domain modules (Nuxt Layers).
See [ADR 0001](../docs/adr/0001-frontend-modular-architecture-nuxt-layers.md) and [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md).
Until a domain migrates, its code follows the current layered structure shown above.
